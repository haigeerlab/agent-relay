## Findings

F1. **The TS CLI opens the upstream default database when `BRIDGE_DB_PATH` is unset** (product, minor). Running
`node ~/.agent-relay/runtime/dist/cli.js retire <name>` directly answered "Unknown agent" for both test names: without
`BRIDGE_DB_PATH` the CLI opened `~/.local/share/claude-codex-bridge/bridge.sqlite`, an empty database left on this Mac
by an earlier upstream install (still 0 agents and 0 messages afterwards; only its modification time changed).
`native_collaboration_retire.py` sets the path and worked. Expected: the CLI refuses without `BRIDGE_DB_PATH` and
points to `native_collaboration_retire.py`, or the docs say to retire only through that script. Reported to the
agent-relay maintainer session; not a release blocker.
